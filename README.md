# 坦克大战 (Tank Battle)

经典 Battle City 风格坦克大战 HTML5 游戏。

## 在线试玩

直接用浏览器打开 `index.html` 即可游玩。

## 操作说明

| 按键 | 功能 |
|------|------|
| ↑ ↓ ← → | 移动坦克 |
| 空格 | 开火 |
| P | 暂停/继续 |

## 游戏特性

- 基于 Canvas 实现，纯前端，无需任何依赖
- 经典地图包含砖墙（可破坏）和钢墙（不可破坏）
- 敌方 AI 自动追踪玩家
- 关卡递进系统（共 5 关），每关敌人数量和强度递增
- 基地（⭐）保护机制
- 爆炸特效与粒子系统
- 护盾保护、子弹碰撞抵消

## 规则

- 共 3 条命，被击中后短暂无敌
- 每击毁一个敌人得 100 分
- 保护基地不被摧毁，否则游戏结束
- 消灭所有敌人进入下一关
